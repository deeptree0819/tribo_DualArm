# p2s_print — 슬라이서 출력용 세트 (40mm 연장형)

Prusa/BambuStudio 등 3MF를 지원하는 슬라이서에서 바로 열어 출력할 수 있도록, 여러 부품을 하나의 빌드 플레이트 배치로 묶어둔 파일입니다. 개별 부품을 하나씩 배치할 필요 없이 세트 단위로 출력하면 됩니다.

| 파일 | 설명 |
|---|---|
| `leader_set1.3mf` | 리더 암 출력 세트 1 |
| `leader_set2.3mf` | 리더 암 출력 세트 2 |
| `follower_set1.3mf` | 팔로워 암 출력 세트 1 |
| `follower_set2.3mf` | 팔로워 암 출력 세트 2 |

각 세트에 포함된 개별 부품 상세 설명은 [`../stl/leader/`](../stl/leader/README.md), [`../stl/follower/`](../stl/follower/README.md)를 참고하세요.
