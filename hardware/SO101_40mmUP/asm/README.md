# asm — SolidWorks 조립체 (40mm 연장형)

40mm 연장형 부품들이 결합된 SolidWorks 조립체(`.SLDASM`) 파일입니다. 개별 부품 편집보다 전체 구조/간섭 확인, 도면 추출에 사용합니다.

| 폴더 | 설명 |
|---|---|
| [`leader/`](./leader/README.md) | 리더 암 조립체 |
| [`follower/`](./follower/README.md) | 팔로워 암 조립체 |

열려면 SolidWorks가 필요하며, 참조하는 개별 파트 파일은 [`../step/`](../step/README.md), [`../stl/`](../stl/README.md) 폴더에 있습니다.
