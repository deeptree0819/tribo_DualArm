# stl — 3D 프린트용 파일 (40mm 연장형)

40mm 연장형 전용으로 새로 설계된 홀더/베이스 파트의 3D 프린트용 STL 파일과 원본 SolidWorks 파트(SLDPRT)입니다. `step/` 폴더의 개별 부품 CAD와 달리, 여기 있는 파일은 대부분 40mm 연장을 위해 추가된 홀더·마운트류입니다.

| 폴더 | 설명 |
|---|---|
| [`leader/`](./leader/README.md) | 리더 암용 출력 파트 |
| [`follower/`](./follower/README.md) | 팔로워 암용 출력 파트 |

바로 슬라이싱해 출력하려면 [`../p2s_print/`](../p2s_print/README.md)의 3MF 세트 파일을 사용하는 것이 더 간편합니다.
